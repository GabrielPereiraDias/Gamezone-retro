# 🎮 GameZone Retro

> 🕹️ **Mini Desafio HTML — Loja de Games Retrô**

Uma página promocional simples criada para representar a **GameZone Retro**, uma loja fictícia especializada em jogos clássicos. O desafio teve como foco praticar os principais elementos do **HTML puro**, mantendo o código compacto, organizado e funcional.

---

## 🚀 Sobre a atividade

O objetivo foi desenvolver uma página com **até 50 linhas de HTML**, reunindo os elementos essenciais de uma página web:

- 📝 Título e parágrafos
- ✨ Textos em **negrito** e *itálico*
- 🎮 Lista de consoles/jogos
- 🔗 Link interno e link externo
- 🖼️ Imagem relacionada ao tema
- 💰 Tabela de produtos e preços

Tudo isso utilizando **HTML puro e simples**, sem depender de CSS ou frameworks.

---

## 🕹️ Tema

### 🎮 GameZone Retro

A proposta simula uma loja voltada para quem curte a nostalgia dos games clássicos, reunindo consoles, jogos e referências da era retrô em uma página promocional compacta.

> **Poucas linhas. Vários elementos. Muita nostalgia.** 👾
